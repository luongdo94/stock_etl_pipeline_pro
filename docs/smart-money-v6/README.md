## 🚀 What's New in v6.0

1. **Money Flow Index (MFI) Cross-Validation**
   - Independent confirmation of OBV signals
   - +15 strength bonus when confirms

2. **Layer 2: Institutional Volume Pattern Detection**
   - Detects large block trades
   - Sector-specific thresholds
   - Earlier detection (+2.3 days)

3. **Volume Quality Scoring (0-100)**
   - Distinguishes institutional vs retail patterns
   - 3 factors: Concentration, Correlation, Consistency

4. **Sector-Specific Thresholds**
   - Tech/Growth: 2.5x average
   - Banks/Financials: 1.8x average
   - Other: 2.0x average

5. **Enhanced Layer 3**
   - Added volume quality component
   - Improved strength scoring
